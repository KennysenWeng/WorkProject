# 工作紀錄表

一個離線、單機、可在 **Mac 與 Windows 通用**的工作紀錄小工具。
雙擊 `工作紀錄.html` 即可用瀏覽器打開，免安裝任何軟體、不需連網路。

---

## 檔案說明

| 檔案 / 資料夾 | 用途 |
|---|---|
| `工作紀錄.html` | App 本體。雙擊用瀏覽器開啟。 |
| `Safari 版啟動.command` | Mac Safari 專用啟動器。雙擊後用 Safari 開啟，並透過本機服務自動讀寫 JSON。 |
| `safari_server.py` | Safari 版啟動器使用的本機服務程式。 |
| `番茄鐘.html` | 獨立的番茄鐘（專注倒數）。雙擊即可單獨用；勾選「自動記一筆」時會寫回同一份 `工作紀錄資料.json`。 |
| `工作紀錄資料.json` | 你的工作紀錄。**會跟著這顆硬碟跨系統移動**，是真正的資料來源。 |
| `專案資料.json` | 你的專案紀錄（第一次存專案時自動建立，與工作紀錄分開存）。 |
| `備份\` | 自動備份（連結資料夾後，每次存檔會在此留時間戳檔；工作紀錄與專案各自備份）。 |
| `匯出\` | 放手動匯出的 CSV / 備份。 |
| `README.md` | 本說明檔。 |

> 這顆硬碟是 **exFAT** 格式，Mac 與 Windows 都能直接讀寫，不需重新格式化。

## 第一次使用

### Chrome / Edge（建議，支援自動存檔＋自動備份）
1. 雙擊 `工作紀錄.html` 打開。
2. 按上方 **「連結工作資料夾」** → 選定硬碟上的 **`工作紀錄`** 這個資料夾 → 允許讀寫。
3. 完成！之後新增 / 修改都會**自動存回** `工作紀錄資料.json`，並自動在 `備份\` 留一份時間戳備份。狀態列會變綠顯示「已自動存檔＋備份」。
4. **下次再打開會記住這個資料夾**：多半會自動接回（狀態列直接變綠）；若瀏覽器要求重新授權（例如完全關掉瀏覽器後），上方會出現一顆 **「接回上次的資料夾」** 按鈕，按一下即可，不必再從檔案視窗找資料夾。

### Safari / Firefox（手動存檔）
1. 雙擊 `工作紀錄.html` 打開。
2. 按 **「載入備份」**，選 `工作紀錄資料.json`。
3. 填寫完畢後按 **「下載 JSON」**，存檔覆蓋原本的 `工作紀錄資料.json`。
4. 還沒存檔就要關視窗時，會跳出提醒避免漏存。
5. （Mac 上若有 Chrome / Edge，建議改用它們以享自動存檔。）

### Mac Safari（自動存檔版）
1. 雙擊 `Safari 版啟動.command`。
2. 若 macOS 第一次詢問是否允許執行，請允許。
3. 系統會打開一個終端機視窗，並自動用 Safari 開啟工作紀錄表。
4. 頁面狀態列顯示 **「Safari 本機存檔啟用」** 時，新增 / 修改會自動寫回 `工作紀錄資料.json` 與 `專案資料.json`，並在 `備份\` 留時間戳備份。
5. 使用期間請保留該終端機視窗開著；要停止時關閉終端機視窗或按 `Control+C`。

## 換電腦使用（Windows ↔ Mac）

1. 在原電腦確認已存檔（Chrome/Edge 自動存；Safari 記得按「下載 JSON」）。
2. 退出硬碟，插到另一台電腦。
   - Windows：通常是 `D:\`、`E:\`、`F:\` 等磁碟。
   - Mac：在 `/Volumes/公司使用/工作紀錄/`，或從 Finder 側邊欄點「公司使用」。
3. 打開同一個 `工作紀錄.html`，連結 / 載入同一份資料，資料就會接續出現。

## 功能一覽

> 頁面頂端有 **「📋 工作紀錄 ｜ 📁 專案」** 頁籤，點一下即可切換兩個畫面（不會同時顯示）。資料夾只要連結一次，兩個畫面共用。

**記錄欄位**：日期、開始/結束時間、工作項目/內容、花費工時、專案/分類、狀態、備註。

**輸入更快**
- ⏱ **計時器**：按「開始計時 / 停止計時」自動填入起訖時間並算出工時。
- 也可直接填開始/結束時間，工時會自動計算（可手動覆蓋）。
- **複製上一筆**：用最後一筆的內容/專案快速建立新紀錄。
- **點狀態快速切換**：清單裡的狀態色塊點一下即可循環切換（進行中 → 完成 → 暫停），不必開編輯。

**🍅 番茄鐘（專注倒數）** — 已獨立成 `番茄鐘.html`，不再佔用主畫面；在工作紀錄表工具列按 **「🍅 番茄鐘」** 會用小浮窗叫出來（也可直接雙擊 `番茄鐘.html` 單獨開）
- 專注 / 短休 / 長休倒數，可自訂分鐘數與「每幾輪長休」。
- 開始 / 暫停 / 重設 / 跳過這段；結束時發出提示音（瀏覽器內建合成，無音檔、純離線）。
- 「自動接續下一段」可一鍵連續循環。
- 顯示「今天完成 🍅 數」（與工作紀錄表共用同一份設定，會同步）。
- 可勾選「完成專注時自動記一筆工作紀錄」，把每次專注直接寫進 `工作紀錄資料.json`（需先在番茄鐘頁按「連結工作資料夾」；Chrome / Edge 支援）。

**📁 專案紀錄表 + 甘特圖**（頂部切到「專案」頁籤）
- 每個專案可記：名稱、開始日期、**預計完成日**、狀態（未開始/進行中/完成/暫停）、進度%、負責人、備註。
- **點狀態快速切換**：專案清單裡的狀態色塊點一下即可循環切換（未開始 → 進行中 → 完成 → 暫停），不必開編輯。狀態顏色與甘特圖一致（進行中黃、暫停藍、完成綠、未開始灰、逾期紅）。
- **清單排序**：自動依狀態優先序排列 **逾期 → 進行中 → 未開始 → 暫停**，同一組內再按開始日期由早到晚。
- **已完成收合區**：完成的專案不混在上面，集中收到清單最下方的 **「▸ 已完成（N）」** 一列，點一下展開、再點收回（預設收合，會記住你的選擇）。
- **子項目／目標**：專案清單列按 `▸` 可**展開勾選清單**，每個子項目有標題、完成勾選、選填的目標日；名稱旁顯示完成數 `(2/4)`。
- **一鍵記到工作清單**：子項目按 **「記工作」**，會在工作紀錄新增一筆（內容＝子項目標題、日期＝今天；**不填專案/分類**）。
- **四象限矩陣**：專案清單右上角切到 **「四象限」**，會出現艾森豪矩陣（上下＝重要/不重要、左右＝緊急/不緊急），把所有專案的子項目當成卡片排在格子裡，下方有「待分類」區。**用滑鼠把卡片拖進想要的象限**即可分類（拖回待分類＝取消分類）。分類後，子項目在清單裡會顯示一個對應顏色的小圓點（🔴重要緊急 / 🔵重要不緊急 / 🟠緊急不重要 / ⚪不重要不緊急）。
  - **已完成的不顯示**：勾完成的子項目會自動從四象限移除，只留下還沒做完的，畫面更乾淨。
  - **每格最多約 5 張、其餘捲動**：單一象限格卡片太多時只占約 5 張高度，超出的在格內用滑鼠滾輪上下捲動。
- **進度自動計算**：專案一旦有子項目，進度% = 已完成數 / 總數（沒有子項目時才用手動填的進度）。
- **甘特圖**：依預計時程畫出每個專案的長條、進度填色、今天線；預計完成日已過且未完成會標**逾期**（紅色）。**有設目標日的子項目**會在該專案長條上顯示為里程碑（◇ 未完成 / ◆ 已完成 / 紅色 逾期）。
  - **隱藏已完成**：甘特圖預設**不顯示「完成」的專案**，讓畫面聚焦在進行中的事；右上角的 **「顯示完成」** 按鈕（會標出隱藏幾筆，例如「顯示完成 (3)」）按一下即可展開，再按 **「隱藏完成」** 收回。這個選擇會記住。
  - **只顯示 7 列、其餘滾輪捲動**：專案多時甘特圖只占約 7 列高度，超出的用滑鼠滾輪在框內上下捲動；最上方的月份刻度會固定不動，方便對齊時間。
- **與工作紀錄相容**：專案名稱對應工作紀錄的「專案/分類」，清單會自動顯示該專案**已累計的實際工時**與**最近活動日**。
- 專案另存 `專案資料.json`，存檔/備份機制與工作紀錄相同；工作紀錄.json 不受影響。

**看得更清楚**
- 清單**依日期分組**，每天顯示「當日小計」。
- **分頁顯示**：清單每頁可選 20 / 25 / 30 筆（預設 25），底部可翻頁；「符合幾筆、合計工時」與「當日小計」仍以全部符合的資料計算，不只本頁。
- **日期區間**：全部 / 今天 / 本週 / 本月 / 自訂；下方顯示「符合幾筆、合計工時」。
- 專案、狀態篩選與關鍵字搜尋。
- **圖表**：每日工時（選「今天」顯示單根長條，選本週/本月等多天自動變成折線趨勢圖，空白日補 0）、各專案工時占比（隨篩選範圍變動，完全離線繪製）。

**資料更安全**
- **連結工作資料夾**後自動存檔，並在 `備份\` 留時間戳備份。
- **離開前未存檔提醒**。
- **匯入 CSV**（附加到現有資料）／**匯出 CSV**（UTF-8，Excel/Numbers 開中文不亂碼）。
- 「下載備份」可隨時存一份時間戳 JSON；專案也有 **「下載專案／載入專案」**（可單獨備份或分享專案，非 Chrome/Edge 也能用）。
- **多視窗自動同步**：番茄鐘浮窗或另一個分頁存檔時，本頁會自動重載，避免用舊資料蓋掉新紀錄。
- **計時器不怕重整**：⏱ 計時進行中即使重新整理頁面也會自動接回。
- 手動填的工時不會被起訖時間自動覆寫（只有工時空白時才自動算）。

**報表與外觀**
- 🖨 **月報**：選月份，產生各專案工時彙總＋每日明細，可直接列印或存成 PDF。
- 🌙 **深色模式**：右上角切換，會記住你的選擇。

## 重要觀念與注意事項

- **資料的真正來源是硬碟上的 `工作紀錄資料.json`**，不是瀏覽器。
  App 會在瀏覽器本機自動暫存一份當防呆，但那份**不會跟著硬碟走**；換電腦時請連結 / 載入硬碟上的資料。
- 不要同時在多個分頁或多台電腦編輯同一份資料，以免互相覆蓋。
- 本工具完全離線運作，不會上傳任何資料。
- `備份\` 會**自動只保留最近 200 份**，更舊的會自動刪除，不需手動清理（每份都是完整快照，留最新的就能還原）。

## 常見問題

**Q：按「連結工作資料夾」沒反應或出錯？**
A：多半是 Safari/Firefox 不支援。改用「載入備份 / 下載 JSON」，或換 Chrome / Edge。

**Q：重新整理後資料還在嗎？**
A：在，會從本機暫存還原。但換電腦時務必連結 / 載入硬碟上的資料。

**Q：CSV 用 Excel 打開中文亂碼？**
A：本工具匯出的 CSV 已加 UTF-8 BOM，正常不會亂碼；若仍亂碼，可在 Excel 用「資料 → 從文字/CSV」選 UTF-8 匯入。
